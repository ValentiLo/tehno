## Задание 4. Провести анализ осуществимости ИС

Ответьте на **шесть вопросов**:

### 4.1. Что произойдёт с организацией, если система не будет введена в эксплуатацию?

**Пример ответа:**
> Замедлится обработка заявок клиентов, увеличится количество ошибок при ручном учёте договоров, возрастут трудозатраты инспекторов и бухгалтерии, снизится качество обслуживания, возможны штрафы от налоговых органов из-за несвоевременной отчётности.

### 4.2. Какие текущие проблемы существуют в организации и как новая система поможет их решить?

| Проблема | Решение с помощью ИС |
|---|---|
| Ручной учёт договоров | Автоматическое хранение и поиск договоров |
| Долгая обработка заявок | Ускорение оформления через электронные формы |
| Ошибки в отчётности | Автоматическое формирование отчётов |
| Сложность контроля оплат | Интеграция с бухгалтерией |

### 4.3. Каким образом (и будет ли) ИС способствовать целям бизнеса?

**Пример:**
> Да, система повысит скорость обслуживания клиентов, снизит операционные расходы, улучшит качество отчётности и обеспечит прозрачность бизнес-процессов.

### 4.4. Требует ли разработка ИС технологии, которая до этого не использовалась в организации?

**Пример:**
> Да, потребуется внедрение **СУБД** (например, PostgreSQL), **веб-технологий** (для доступа через браузер), **средств шифрования** персональных данных клиентов.

### 4.5. Где будет размещена ИС? Кто является пользователем ИС?

**Пример:**
> Система размещается на **сервере организации** (или в облаке). Пользователи: инспекторы, бухгалтеры, администраторы, менеджеры.

### 4.6. Комплекс технических средств ИТ

Опишите **четыре группы** средств:

#### 1. Средства компьютерной техники
- Серверы (для хранения БД).
- Рабочие станции (ПК инспекторов, бухгалтеров).
- Ноутбуки для выездных сотрудников.
- Устройства хранения (NAS, RAID-массивы).

#### 2. Средства коммуникационной техники
- Локальная сеть (коммутаторы, маршрутизаторы).
- Интернет-канал.
- Wi-Fi точки доступа.
- IP-телефония.

#### 3. Средства организационной техники
- МФУ (принтер, сканер, копир).
- Шредеры.
- Специализированные сканеры документов.

#### 4. Средства оперативной полиграфии
- Принтеры для печати договоров и бланков.
- Ламинаторы (для карт клиентов).

### 4.7. Системное ПО ИТ

Опишите **системное программное обеспечение**:

| Категория | Примеры |
|---|---|
| **Операционные системы** | Windows Server, Linux (Ubuntu Server) |
| **СУБД** | PostgreSQL, MySQL, MS SQL Server |
| **Веб-серверы** | Apache, Nginx |
| **Среды разработки** | Visual Studio, IntelliJ IDEA, PyCharm |
| **Системы контроля версий** | Git, GitLab |
| **Антивирусы** | Kaspersky, Dr.Web |
| **Средства резервного копирования** | Veeam, rsync |

## Пример готового ответа (для страховой компании)

**Предметная область:** Страховая медицинская компания  
**Название ИС:** «ИС учёта договоров добровольного медицинского страхования»  
**Цель ИС:** Автоматизация учёта договоров, страховых случаев, взаимодействия с лечебными учреждениями и формирования отчётности.

**Анализ осуществимости:**

| Вопрос | Ответ |
|---|---|
| Что будет без системы? | Ручной учёт, ошибки, задержки, штрафы |
| Текущие проблемы | Медленная обработка заявок, ошибки в отчётах |
| Связь с целями бизнеса | Ускорение обслуживания, снижение расходов |
| Новые технологии? | СУБД, веб-технологии, шифрование |
| Где размещена? | Сервер организации |
| Пользователи | Инспекторы, бухгалтеры, администраторы |

**КТС:**
- Компьютерная техника: серверы, ПК, NAS.
- Коммуникационная: ЛВС, интернет, Wi-Fi.
- Организационная: МФУ, сканеры, шредеры.
- Полиграфия: принтеры для договоров, ламинаторы.

**Системное ПО:**
- ОС: Windows Server / Linux.
- СУБД: PostgreSQL.
- Веб-сервер: Nginx.
- Контроль версий: Git.
