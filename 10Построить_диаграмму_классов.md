**Предметная область:** Кадровое агентство

---

## 1. Выбранные сущности

Для диаграммы классов выбраны **4 ключевые сущности**:

| Сущность | Назначение |
|---|---|
| **Соискатель (Applicant)** | Безработный гражданин, ищущий работу |
| **Резюме (Resume)** | Документ с данными соискателя |
| **Вакансия (Vacancy)** | Свободная должность от предприятия |
| **Назначение (Assignment)** | Связь соискателя и вакансии |

---

## 2. Текстовое описание классов

### Класс `Applicant` (Соискатель)

**Атрибуты:**
- `id: int` — уникальный идентификатор
- `fullName: string` — ФИО
- `birthDate: date` — дата рождения
- `phone: string` — телефон
- `email: string` — email
- `education: string` — образование
- `specialty: string` — специальность
- `experience: int` — опыт работы (лет)
- `status: string` — статус (безработный / трудоустроен)

**Методы:**
- `register()` — регистрация
- `updateProfile()` — обновление данных
- `addResume()` — добавление резюме
- `getResumes()` — получить список резюме

---

### Класс `Resume` (Резюме)

**Атрибуты:**
- `id: int` — уникальный идентификатор
- `applicantId: int` — ID соискателя
- `desiredPosition: string` — желаемая должность
- `desiredSalary: decimal` — желаемая зарплата
- `skills: string` — ключевые навыки
- `additionalInfo: string` — дополнительная информация
- `updatedAt: date` — дата обновления

**Методы:**
- `create()` — создать резюме
- `edit()` — редактировать
- `delete()` — удалить
- `getSkills()` — получить навыки

---

### Класс `Vacancy` (Вакансия)

**Атрибуты:**
- `id: int` — уникальный идентификатор
- `employerId: int` — ID работодателя
- `position: string` — должность
- `requirements: string` — требования
- `salaryFrom: decimal` — зарплата от
- `salaryTo: decimal` — зарплата до
- `schedule: string` — график работы
- `status: string` — статус (открыта / закрыта)
- `publishedAt: date` — дата публикации

**Методы:**
- `publish()` — опубликовать
- `edit()` — редактировать
- `close()` — закрыть
- `isOpen()` — проверить статус

---

### Класс `Assignment` (Назначение)

**Атрибуты:**
- `id: int` — уникальный идентификатор
- `applicantId: int` — ID соискателя
- `vacancyId: int` — ID вакансии
- `recruiterId: int` — ID рекрутера
- `assignedAt: date` — дата назначения
- `status: string` — статус (предложено / собеседование / трудоустроен / отказ)
- `comment: string` — комментарий

**Методы:**
- `assign()` — назначить
- `changeStatus()` — изменить статус
- `confirmEmployment()` — подтвердить трудоустройство

## 4. Связи между классами

| Связь | Тип | Описание |
|---|---|---|
| **Applicant → Resume** | 1 : * | Один соискатель может иметь несколько резюме |
| **Vacancy → Assignment** | 1 : * | На одну вакансию может быть несколько назначений |
| **Applicant → Assignment** | 1 : * | Один соискатель может быть назначен на несколько вакансий |
| **Resume → Assignment** | — | Через соискателя |

**Кратности:**

```
Applicant 1 ──────── * Resume
Applicant 1 ──────── * Assignment
Vacancy   1 ──────── * Assignment
```

---

## 5. Пояснение к диаграмме

### 5.1. Соискатель и Резюме

- **Один соискатель** может создать **несколько резюме** (например, для разных должностей).
- Связь **1 : *** — «один ко многим».
- Если соискатель удаляется — его резюме тоже (каскадное удаление).

### 5.2. Вакансия и Назначение

- **Одна вакансия** может иметь **несколько назначений** (разные соискатели).
- Связь **1 : *** — «один ко многим».

### 5.3. Соискатель и Назначение

- **Один соискатель** может быть назначен на **несколько вакансий**.
- Связь **1 : *** — «один ко многим».

### 5.4. Роль Рекрутера

- В классе `Assignment` есть поле `recruiterId` — **кто назначил**.
- Рекрутер — это **отдельная сущность** (не включена в диаграмму для простоты).

## 7. Пример кода (Python)

```python
class Applicant:
    def __init__(self, id, full_name, birth_date, phone, email):
        self.id = id
        self.full_name = full_name
        self.birth_date = birth_date
        self.phone = phone
        self.email = email
        self.education = ""
        self.specialty = ""
        self.experience = 0
        self.status = "безработный"
        self.resumes = []
    
    def add_resume(self, resume):
        self.resumes.append(resume)
    
    def get_resumes(self):
        return self.resumes


class Resume:
    def __init__(self, id, applicant_id, desired_position):
        self.id = id
        self.applicant_id = applicant_id
        self.desired_position = desired_position
        self.desired_salary = 0
        self.skills = ""
        self.additional_info = ""
        self.updated_at = None
    
    def edit(self, position, salary, skills):
        self.desired_position = position
        self.desired_salary = salary
        self.skills = skills


class Vacancy:
    def __init__(self, id, employer_id, position):
        self.id = id
        self.employer_id = employer_id
        self.position = position
        self.requirements = ""
        self.salary_from = 0
        self.salary_to = 0
        self.schedule = ""
        self.status = "открыта"
        self.assignments = []
    
    def close(self):
        self.status = "закрыта"
    
    def is_open(self):
        return self.status == "открыта"


class Assignment:
    def __init__(self, id, applicant_id, vacancy_id, recruiter_id):
        self.id = id
        self.applicant_id = applicant_id
        self.vacancy_id = vacancy_id
        self.recruiter_id = recruiter_id
        self.assigned_at = None
        self.status = "предложено"
        self.comment = ""
    
    def change_status(self, new_status):
        self.status = new_status
    
    def confirm_employment(self):
        self.status = "трудоустроен"
```

## 8. Итог

**Диаграмма классов** для ИС «КадрПро» содержит **4 ключевые сущности**:

| Класс | Связь |
|---|---|
| **Applicant** | 1 : * с Resume |
| **Resume** | * : 1 с Applicant |
| **Vacancy** | 1 : * с Assignment |
| **Assignment** | * : 1 с Applicant и Vacancy |

**Связи:** «один ко многим» — соискатель → резюме, вакансия → назначения, соискатель → назначения.

**Дополнительно:** можно добавить сущности **Работодатель (Employer)** и **Рекрутер (Recruiter)** для полноты модели.
